# ML Lab

A flexible public laboratory for selected ML/AI practice: compact notebooks,
from-scratch implementations, and bounded experiments.

This repository exists to strengthen fundamentals and make learning inspectable.
It does not commit Santiago to a domain or require every exploration to become a
portfolio project.

## Areas

- `notebooks/`: question-driven analyses and compact public-dataset exercises.
- `from_scratch/`: implementations that expose important model or optimization
  mechanics.
- `experiments/`: bounded comparisons and feasibility probes that may inform a
  later project.

Every published exercise should state the question, baseline, validation design,
metric rationale, result, failure analysis, and reproduction steps. Tooling and
project conventions will be standardized when the first exercise creates a real
need.
