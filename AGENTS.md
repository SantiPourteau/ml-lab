# Agent instructions

- Read `README.md` and `docs/PROJECT.md` before working.
- Keep this repository open across ML/AI domains and techniques.
- Each exercise starts with a question and evaluation plan, not a preferred
  model.
- Check leakage, split validity, baseline quality, and reproducibility.
- Explain negative or inconclusive results honestly.
- Do not promote every experiment as portfolio work.
- Avoid large data, model binaries, credentials, and generated artifacts in Git.
- Add shared tooling only when the first concrete exercise requires it.
- Do not commit, push, or create remote resources without user direction.
